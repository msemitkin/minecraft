# ⛏ MineClone

Клон Minecraft, який працює прямо в браузері. Написаний на JavaScript + [Three.js](https://threejs.org/), без жодних зовнішніх ассетів — усі текстури генеруються процедурно на canvas.

## Можливості

- 🌍 **Нескінченний процедурний світ** — рельєф на основі value noise (рівнини, пагорби, гори, озера)
- 🧱 **Чанкова система** — світ генерується та рендериться чанками 16×64×16 навколо гравця
- 🌲 **Дерева** — процедурно розставлені, коректно перетинають межі чанків
- 💧 **Вода з фізикою** — тече вниз, обмежено розтікається вбік, потоки без джерела висихають; плавання
- 🧨 **Динаміт** — удар підпалює (миготить ~2 с), вибух руйнує блоки сферою, детонує сусідній динаміт ланцюгом і відкидає гравця та тварин
- ⛏ **Поетапний видобуток** — блоки добуваються за кілька ударів (утримуй ЛКМ); тріщини наростають у 10 стадій, час залежить від міцності блока, а кирка від першої особи махає й похитується при ходьбі
- 🧱 **Встановлення блоків** — 13 типів блоків (зокрема вода, динаміт і руди); меню вибору (`Tab`) дає доступ до всіх, а 10 слотів хотбара (`1`–`9`, `0`) — швидкий доступ до улюблених
- 💎 **Руди** — вугілля, залізо, золото й алмаз генеруються жилами в камені (рідкісніші — глибше), добуваються повільніше за камінь і ставляться як декоративні блоки
- 🐷 **Тварини** — свинки, корови й кури блукають світом, перестрибують перешкоди та плавають
- 🧟 **Зомбі та ближній бій** — уночі зʼявляються вороги, що переслідують і бʼють гравця; удар `ЛКМ` влучає по зомбі (відкид, спалах, загибель хмаркою частинок), а на світанку незахищені зомбі згоряють
- 🚶 **Фізика гравця** — гравітація, стрибки, біг, колізії по AABB
- ❤️ **Виживання** — здоров'я (10 сердець у HUD), шкода від падіння, потоплення із запасом повітря (шкала бульбашок), шкода від близького вибуху, природна регенерація, червоний спалах при ударі та екран смерті з відродженням
- 🕳 **Печери** — 3D-шум вирізає мережі тунелів у надрах, зрідка з виходами на поверхню
- 💾 **Збереження світу** — зміни блоків, позиція гравця й час доби автоматично зберігаються в localStorage; кнопка «Нова гра» скидає світ
- 🌅 **Цикл день/ніч із небесними тілами** — видимий диск сонця, місяць із кратерами, мерехтливе зоряне небо (≈1400 зір, що обертаються разом із небосхилом), тепле сяйво на сході/заході та динамічний туман
- ☁️ **Хмари** — шар процедурних пухнастих хмар, що дрейфує небом за вітром, біліє вдень, синіє вночі та теплішає на сході/заході (нуль зовнішніх ассетів)
- ✨ **Частинки** — руйнування блока розкидає уламки в кольорі його текстури, встановлення дає легкий пил, а вибух динаміту здіймає дим і розжарені іскри (усе на одному `InstancedMesh`)
- 🔊 **Процедурний звук** — кроки (тембр залежить від матеріалу), видобуток, встановлення, стрибок/приземлення, сплеск у воді, ґніт і вибух динаміту, удари й стогони зомбі, шкода гравцю — усе синтезується через Web Audio API без жодних аудіофайлів; вимикач 🔊/🔇 (клавіша `M`)
- 🎯 **Підсвічування блока** під прицілом, прицел, хотбар, дебаг-панель (FPS, координати)

## Запуск

Потрібен будь-який локальний веб-сервер (ES-модулі не працюють із `file://`):

```bash
# Python
python3 -m http.server 8000

# або Node.js
npx serve .
```

Далі відкрийте [http://localhost:8000](http://localhost:8000) у браузері та натисніть **«Грати»**.

> Three.js підвантажується з CDN, тому потрібен доступ до інтернету.

## Керування

| Клавіша | Дія |
|---|---|
| `W` `A` `S` `D` | Рух |
| `Space` | Стрибок / плисти вгору |
| `Shift` | Біг |
| `ЛКМ` (утримувати) | Добувати блок / ударити зомбі в прицілі |
| `ПКМ` | Поставити блок |
| `1`–`9`, `0` / колесо миші | Вибір слота хотбара |
| `Tab` | Меню всіх блоків (призначити блок у активний слот) |
| `M` | Увімкнути / вимкнути звук |
| `Esc` | Пауза |

### 📱 На сенсорних пристроях

Гра автоматично перемикається в мобільний режим: віртуальний джойстик ліворуч — рух, свайп по екрану — камера, кнопки праворуч — стрибок (⬆), зруйнувати блок (⛏, можна тримати), поставити блок (▦) і меню всіх блоків (▤). Слот хотбара вибирається тапом.


## Як це працює

- **Генерація**: висота рельєфу — fBm з 4 октав value noise; дерева розставляються детерміністичним хешем координат, тому світ відтворюваний і безшовний між чанками.
- **Мешинг**: для кожного чанка будується один меш — рендеряться лише видимі грані блоків (face culling по сусідах), вода йде окремим прозорим мешем.
- **Текстури**: атлас 4×4 тайлів 16×16 px малюється на canvas при старті (`NearestFilter` для піксельного вигляду).
- **Фізика**: рух гравця розв'язується по осях окремо проти AABB твердих блоків.
- **Зміни світу** зберігаються в мапі правок і повторно застосовуються при регенерації чанків.
